DEPLOY STEPS:
1. ZIP extract karein.
2. shilpi-public-site folder ke ANDAR ki sabhi files GitHub repository ke root mein upload/replace karein. Folder ko nested folder ke roop mein upload na karein.
3. Commit changes karein. Vercel automatic deploy karega.
4. Vercel deploy complete hone ke baad website refresh karein.

Supabase config file mein sirf publishable key honi chahiye. Secret/service_role key kabhi frontend ya GitHub mein na daalein.

NOTE: Candidate login/signup Supabase Auth par based hai. Blog post ke liye Admin panel aur Supabase schema/config zaroori hain. WhatsApp enquiry user ke WhatsApp mein message prefill karti hai; user ko Send dabana hota hai.
